## Melhorias:
As melhorias realizadas foram:
- A mudança da tipografia, afim de tornar melhor a legibilidade.
- Mudança nas cores, tornando menos irritante para os olhos.
- Organização de notícias em pequenos blocos.
- Melhor design. 

## Elementos semânticos:
Os elementos semânticos usado na construção da página foram:
- Header: para o cabeçalho
- Main: para o corpo principal da página
- Footer: para o rodapé

### Header:
No header foi usado as tags *section*, *span* e *h1*, *header*.
### Main:
Na main foram usados, *section*, *p*, *h2*, *h1*, *span*, *table*, *th, tr, td*, *main*.
### Footer:
No footer foi usado, *Section*, *p*, *ul e li*, *nav*, *footer*.

## Media Queries
Foram feitas as medias queires de tablets e celulares
tablets: de 480 a 1024 pixeis
celular: menos de 480 pixeis

## Decisões de UX e UI
A decisão de organizar as noticias, criar uma navegação, barra de pesquisa e mudança de cores, foi visando a melhor uso do site pelo usuário, deixando mais fácil e simples de usar.
